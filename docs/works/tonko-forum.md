# とんこう地域フォーラム特設サイト

![とんこう地域フォーラム特設サイト](/img/works/e_forum.webp)

<WorksCta url="https://forum.tonko.ed.jp/" />

大阪府立富田林中学校・高等学校が主催する、地域を巻き込んだ科学イベント「とんこう地域フォーラム」の特設サイトを制作しました。

イベント関連情報や催しの一覧・申し込み方法などについて、詳細な案内を実施しています。

また、画面遷移時にエフェクトを搭載し、独自性をもたせるほか、楽しいイベントの演出としています。
