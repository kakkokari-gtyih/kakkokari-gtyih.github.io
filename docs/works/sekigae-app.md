# 高機能席替えアプリ Sekigae.app

![Sekigae.app](/img/works/e_sekigae.webp)

<WorksCta url="https://sekigae.app/" />

独自アルゴリズムを採用し、特定の生徒の座席を前寄りにする・左寄りにするなどの「優先配置」を考慮した席替えを可能とした席替えアプリです。

他のアプリで利用できる「特定生徒の固定配置」や「座席発表時の演出」などはもちろん、「CSV形式でのインポート・エクスポート」などの業務効率化に役立つ機能まで、多彩な機能を搭載しています。

## 技術スタック

- Nuxt.js (Vue.js v3)
- Nuxt UI
- Tailwind CSS
