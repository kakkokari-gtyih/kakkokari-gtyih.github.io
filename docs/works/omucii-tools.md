# 情報基盤センター Tools

![情報基盤センター Tools](/img/works/o_tools.webp)

<WorksCta url="https://tools.cii.omu.ac.jp/" />

大阪公立大学情報基盤センターが提供する各種ツール群「情報基盤センター Tools」のフロントエンド開発を担当しました。情報基盤センター Toolsは、学生や教職員が利用する便利ツールをまとめたウェブアプリです。現在以下のようなツールが提供されています。

- 利用者検索：学内の教職員・学生の情報を検索できるツール
- パスワード共有ツール：SSOと連携して安全にパスワードを共有できるツール
- 合理的配慮情報共有ツール：障がいを抱えているなど、授業時や試験時に合理的配慮が必要な学生の情報を共有するツール

このプロジェクトにおいて、フロントエンドの開発・ドキュメントの整備を担当しました。

レスポンシブ対応の改善・ダークモード実装・多言語対応などの旧ツールからの課題を解決したほか、全体的な操作性の向上・パフォーマンスの向上・軽量化を実現しました。

デザインでは、旧ツールでは属性を色のみで区別・表現していたところを、アイコンを多用したり、色の表示領域を拡大して判別しやすくしたりといった改善を加えました。

## 担当内容

- バックエンド全般：他の学生スタッフが担当
- フロントエンド全般：かっこかり
- 操作マニュアル整備：かっこかり＋他の学生スタッフ
