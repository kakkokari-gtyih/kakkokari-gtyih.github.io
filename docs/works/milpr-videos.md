# ミリサーチβ＋私を構成する6本のミリプロ動画

![Moodle Plus](/img/works/e_milprvideos.png)

<WorksCta url="https://milpr.vstreams.app/" />

VTuberプロダクション「ミリプロ」の過去・現在・今後の配信や動画アーカイブを検索・閲覧できるデータベースサイト。

ただ配信や動画の情報を収集・蓄積するだけでなく、最新技術をもって出演者の情報を可視化・絞り込めるようにしています。

ユーザー参加型の機能として、本データベースに収録されている動画や配信からとっておきのものを6本選んで、「私を構成する6本のミリプロ動画」としてSNSにシェアする機能を備え、本サイトそのもののリーチ向上やファン同士の交流を促進しています。

本プロジェクトにおいて、フロントエンド領域を担当しました。特に個人別のページにおいて、公式サイトを意識したデザインとユーザー体験の実装をこだわりました。
