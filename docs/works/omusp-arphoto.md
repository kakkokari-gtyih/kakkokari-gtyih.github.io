# 大阪公立大学ARフォトフレーム

![大阪公立大学ARフォトフレーム](/img/works/o_arphoto.webp)

各種イベントでエンゲージメントコンテンツとして使用できる「2D/3D ARフォトフレーム」とそのランディングページを、素材と設定ファイルを追加するだけで簡単にいくつでも作製できるフレームワークとして開発しました。

本フレームワークは、3Dモデルを現実世界上に配置して写真を取る「3D AR」と、2D画像をカメラ映像と合成して写真を取る「2D AR」の両方に対応しています。3D ARについては &lt;model-viewer&gt; を使用しており、2D ARについてはカメラ映像との合成やオブジェクトの移動・拡大縮小・回転などの操作を実現する独自の描画処理を実装しています。どちらのARコンテンツも、すべての処理をブラウザ上で完結させており、アプリの別途ダウンロードなどの手間無く、気軽に利用できるようになっています。

本企画は入学式・卒業式を所管する学生課の依頼を受けて制作したもので、まずは2025年度春季学位記授与式（卒業式）にてAR立て看板として活用されました。今後順次その他のイベント（2027年度以降の入学式や、学会などの単発イベント）にも展開予定です。

## 技術スタック

- Astro
- Vue.js v3
- &lt;model-viewer&gt;
- UnoCSS
- 大阪公立大学 学生プロジェクト フロントエンド共通ライブラリ
