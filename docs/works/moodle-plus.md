# Moodle Plus

![Moodle Plus](/img/works/e_moodleplus.webp)

<WorksCta url="https://moodle-plus.github.io/" />

授業支援システムの機能を拡張し、提出期限が迫っている課題などを一覧表示できるブラウザ拡張機能「Moodle Plus」のメンテナをしています。プロジェクトリーダー（現在修士１年生）の方と一緒に機能拡張やバグ修正などを継続的に行っています。

※この拡張機能は、Moodle ProjectやMoodleを使用する機関とは一切関係ありません。

## 技術スタック

### 拡張機能本体

- TypeScript
- WXT

### インストールトランポリンサイト

- Astro
- Tailwind CSS
