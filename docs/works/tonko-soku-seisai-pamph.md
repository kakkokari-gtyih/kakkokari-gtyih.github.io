# 文化祭パンフレット

<img src="/img/works/e_sokus.webp" alt="文化祭パンフレット" class="my-4 mx-auto w-auto! h-full max-h-[70svh]" />

大阪府立富田林中学校・高等学校文化祭「<ruby>蒼<rt>そう</rt></ruby><ruby>空<rt>くう</rt></ruby><ruby>星<rt>せい</rt></ruby><ruby>彩<rt>さい</rt></ruby>」の総合演出担当として、公式パンフレットの紙面デザインを制作しました。パンフレットは来場者に配布され、文化祭のプログラムや会場マップなどが掲載されています。

今回のパンフレットでは、来場者の利便性向上のため、紙面を2ページから12ページに大幅に増強し、企画内容を網羅しました。また、デザイン面では、文化祭のテーマである「蒼空星彩」を反映させるため、青空や星空をモチーフにしたビジュアルを採用し、全体的に統一感のあるデザインに仕上げました。

企画ページでは、デザインの簡略化のためにフォームのデータをそのまま取り込むことで紙面を自動生成するプログラムを開発し、急な変更にも対応できるように工夫しました。

さらに、後の世代に使いやすいようPowerPoint形式でのデザインシステムの作成も実施しています。

## 担当内容

- キービジュアル・背景・ロゴデザイン：別の生徒が担当
- 紙面レイアウト・デザイン：かっこかり
- 企画ページの自動生成プログラム開発：かっこかり

## 使用技術

- Microsoft PowerPoint
- Inkscape
- 出し物紹介自動生成プログラム
  - TypeScript
  - Vue.js v3
  - Paged.js
